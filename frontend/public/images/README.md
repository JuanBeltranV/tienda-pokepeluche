# Imágenes provisionales

SVG originales de un compañero de peluche genérico, creados para este proyecto.
`hero-companion.svg` es la ilustración base. Las variantes sage, peach, blue y
yellow cambian su paleta; no pretenden reproducir el aspecto de un Pokémon.

Son placeholders locales, sin logos oficiales, URLs remotas ni dependencias de
PokéAPI. La interfaz los identifica como ilustraciones provisionales. Sustituir
por imágenes definitivas autorizadas cuando estén disponibles.

`emerald-route.svg` es el paisaje pixel art original del rediseño Emerald:
bosque, laguna, tienda y compañero genérico. No contiene sprites extraídos
del videojuego ni recursos del sitio oficial de Pokémon.
